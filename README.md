# Abstention is not Refusal — Paper Code

Code for the paper *"Abstention is not Refusal, but it Affects Safety of Large Language Models."*
It covers the full pipeline: geometry of the abstention (`v_abs`) vs refusal (`v_ref`) directions,
cross-task abstention induction/suppression, response frames, the reverse-steering jailbreak,
operating-point selection, and human validation.

This is a **from-scratch** release: no benchmark text or model outputs are shipped. The public
source datasets are fetched by a script; the pipeline then runs from model weights (GPU) and an
OpenAI-compatible API for the LLM judge. It reproduces the *method* and gives results close to the
paper; it does not reproduce the paper's exact frozen item selection.

## Setup

```bash
conda env create -f environment.yml     # or: pip install -r requirements.txt
cp .env.example .env.local               # fill OPENROUTER_API_KEY (LLM judge, e.g. gpt-4o-mini)
export ABST_PKG=$(pwd)
```

Model weights are pulled by HF Hub id (`src/steering/instruction_config.py`); point
`HF_HOME`/`HF_HUB_CACHE` at a local snapshot to run offline.

## 1. Fetch the datasets

```bash
python3 scripts/prepare_data.py
```

Downloads the public sources into `data/` (nothing is redistributed in this repo):
SQuAD 2.0, AdvBench, Alpaca via HuggingFace; UMWP and FalseQA from their public repositories.
Licenses, attribution, and the responsible-use notice are in
[`DATA_LICENSES.md`](DATA_LICENSES.md); the `sample_id` scheme is in
[`DATA_PROVENANCE.md`](DATA_PROVENANCE.md). TriviaQA (the answerable control) is generated by
step 00 below.

## 2. Per-model pipeline

Run once per model (`RUN_ID` / `MODEL_KEY` from `configs/v2_defaults.env`):

```bash
bash scripts/v2/00_generate_controlled_test.sh   # controlled TriviaQA pool (API)
bash scripts/v2/01_prepare_splits.sh             # cue_extract / dev / test splits (seeded)
bash scripts/v2/02_extract_vectors_geometry.sh   # cue_diff -> SVD -> comp1 (=v_abs)
bash scripts/v2/02b_extract_refusal_vectors.sh   # AdvBench - Alpaca -> v_ref
bash scripts/v2/03_build_calibration_jobs.sh
bash scripts/v2/04_run_calibration_generation.sh
bash scripts/v2/05_judge_calibration.sh          # LLM judge (gpt-4o-mini)
bash scripts/v2/06_select_params.sh              # operating point (L*, c*)
bash scripts/v2/07_build_eval_jobs.sh
bash scripts/v2/08_run_eval_generation.sh
bash scripts/v2/09_judge_eval.sh
bash scripts/v2/10_summarize_plot.sh
```

## 3. Cross-model analyses (produce the paper numbers)

The LLM judge everywhere is `src/analysis/ml_judge.py` (gpt-4o-mini).

```bash
# §4.1 geometry: cos(v_abs,v_ref), |cos|(cue_diff,v_abs), SVD PVE
python3 src/analysis/geometry_final.py

# §4.2 induction / suppression (Table 7)
bash scripts/run_v1sel_generation.sh && bash scripts/run_supp_v1sel_generation.sh
bash scripts/run_judge_v1sel.sh       && bash scripts/run_judge_supp_v1sel.sh

# §4.2 response frames (Fig 4)
python3 src/analysis/compute_frames.py

# §4.3 reverse-steering jailbreak, validity-gated non-refusal (Table 8)
#   generations judged by src/analysis/wildguard_harm_check.py (WildGuard)
python3 src/analysis/compute_nonref_valid.py

# Table 5 operating points: Stage-A layer sweep and Stage-B dose
python3 src/analysis/judge_joint_sweep.py && python3 src/analysis/analyze_joint_sweep.py
python3 src/analysis/judge_dose.py        && python3 src/analysis/analyze_comp1_dose.py
```

## 4. Human validation (Table 6)

```bash
python3 src/analysis/build_human_audit_200.py     # blinded 200-item sheets from the generations
# a human fills the [TAG]: labels in human_label_200/*.md (blinded to model / condition / verdict)
python3 src/analysis/score_human_audit_200.py --dir human_label_200   # agreement / kappa
```

The builder is deterministic (`seed=20260804`), so the sampled items are reproducible; the labels
are the human input.

## Layout

```text
scripts/prepare_data.py   fetch the public datasets into data/
scripts/v2/               00–10 per-model pipeline
scripts/                  cross-model generation / judge drivers
src/steering/             extraction, steering, campaign runner, selection
src/analysis/             geometry, LLM + WildGuard judges, sweep/dose analysis, number reproducers, human-audit build+score
configs/v2_defaults.env   run configuration (models, paths, judge = gpt-4o-mini)
```

## Data, licenses, and responsible use

No benchmark inputs or model generations are shipped; `scripts/prepare_data.py` fetches the public
datasets, each under its own license — see [`DATA_LICENSES.md`](DATA_LICENSES.md). The
reverse-steering experiment applies AdvBench harmful prompts and produces unsafe model outputs when
refusal is broken; those outputs are generated locally at run time and are **not** included here.
Use is for research reproduction only. Code is MIT ([`LICENSE`](LICENSE)); the MIT grant does not
extend to the fetched datasets.
