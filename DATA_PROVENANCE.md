# Data provenance

No benchmark text is shipped. `scripts/prepare_data.py` fetches the public source datasets and
writes the pipeline inputs under `data/` (see [`DATA_LICENSES.md`](DATA_LICENSES.md) for sources,
licenses, and terms).

## Sources and `sample_id` scheme

Each fetched item gets a stable `sample_id = "<DatasetClass>:<source_index>"`, where
`source_index` is the row index into the public source:

| `sample_id` prefix | `dataset` | Public source | `source_index` |
|---|---|---|---|
| `Squad2Dataset:<i>` | `squad2` | SQuAD 2.0 (`rajpurkar/squad_v2`, validation) | row index |
| `UMWP:<i>` | `umwp` | UMWP (`Yuki-Asuuna/UMWP`, `StandardDataset.jsonl`) | item `id` |
| `FalseQADataset:<i>` | `falseqa` | FalseQA (`thunlp/FalseQA`, `dataset/exp-3`) | row index |
| `advbench:<i>` | `advbench` | AdvBench (`walledai/AdvBench`) | row index |
| `alpaca:<i>` | `alpaca` | Alpaca (`tatsu-lab/alpaca`, instruction-only) | row index |
| `controlled:<split>:<entity>:<cond>` | `controlled` | TriviaQA control pool, generated by `scripts/v2/00_generate_controlled_test.sh` | — |
| `trivia:val_<i>` | `trivia` | TriviaQA (`mandarjoshi/trivia_qa`, validation) | validation index |

`should_abstain` is the unanswerability label: SQuAD 2.0 impossible questions, UMWP
`answerable=false`, FalseQA false-premise (`label=1`); TriviaQA is the answerable control.

## Splits

`scripts/v2/01_prepare_splits.sh` draws three disjoint splits from the fetched pool by a fixed seed
(`cue_extract` for direction extraction, `dev` for operating-point selection, `test` for evaluation),
so the split is reproducible given the same fetched data. Because the fetched pool is the raw public
data rather than the paper's normalized/curated pool, the exact items differ from the paper — this
release reproduces the method and close results, not the identical frozen selection.
